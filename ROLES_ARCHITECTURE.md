# Архитектура ролей и личных кабинетов HARD CASE

## Роли в системе

### 1. Client (Клиент)
- Пользователи, которые тренируются
- Видят свои тренировки, питание, прогресс
- Могут общаться со своим тренером

### 2. Trainer (Тренер)
- Ведут клиентов
- Создают программы тренировок
- Назначают питание
- Просматривают прогресс клиентов

### 3. Admin (Администратор)
- Управляют системой
- Назначают тренеров клиентам
- Видят статистику

## Структура страниц

```
/dashboard/client   - Личный кабинет клиента
/dashboard/trainer  - Личный кабинет тренера
/dashboard/admin    - Админ-панель
```

### Редирект логика:
```
/dashboard → автоматический редирект в зависимости от роли:
  - client → /dashboard/client
  - trainer → /dashboard/trainer
  - admin → /dashboard/admin
```

## Регистрация и назначение ролей

### Самостоятельная регистрация:
- ✅ **РЕШЕНИЕ:** Только клиенты могут самостоятельно регистрироваться
  - Форма `/login` доступна всем
  - При регистрации автоматически присваивается роль `client`
  - Тренеры и админы НЕ могут самостоятельно зарегистрироваться

### Назначение ролей:
- ✅ **РЕШЕНИЕ:** Через админ-панель
  - Админ может создавать новых пользователей с ролью `trainer`
  - Админ может повышать существующих пользователей (client → trainer, trainer → admin)
  - Админ может понижать роли (если нужно)
  - Первый админ создается вручную через SQL:
    ```sql
    -- Создать первого администратора
    UPDATE profiles
    SET role = 'admin'
    WHERE user_id = (SELECT id FROM auth.users WHERE email = 'admin@hardcase.training');
    ```

## Функционал по ролям

### Client Dashboard (/dashboard/client)

**Доступные секции:**
1. **Профиль** - личная информация, замеры
2. **Мои тренировки** 💪
   - Текущая программа тренировок
   - История тренировок
   - Логирование выполненных упражнений

3. **Питание** 🥗
   - Цели по КБЖУ
   - Дневник питания
   - Фото еды

4. **Прогресс** 📊
   - Графики веса и замеров
   - Фото прогресса
   - Ежемесячные отчеты от тренера

5. **Мой тренер**
   - Информация о тренере
   - Чат/сообщения

**НЕ может:**
- Создавать программы тренировок для других
- Видеть других клиентов
- Изменять свою роль

### Trainer Dashboard (/dashboard/trainer)

**Доступные секции:**
1. **Мои клиенты**
   - Список всех клиентов
   - Статус каждого клиента
   - Быстрый доступ к прогрессу

2. **Программы тренировок**
   - Создание программ
   - Назначение клиентам
   - Шаблоны программ

3. **Питание для клиентов**
   - Расчет КБЖУ
   - Назначение планов питания

4. **Прогресс клиентов**
   - Просмотр фото прогресса
   - Замеры и графики
   - Создание ежемесячных отчетов

5. **Сообщения**
   - Общение с клиентами

**НЕ может:**
- Управлять пользователями системы
- Назначать других тренеров
- Менять роли

### Admin Dashboard (/dashboard/admin)

**Доступные секции:**
1. **Управление пользователями**
   - Список всех пользователей
   - Создание тренеров/админов
   - Изменение ролей
   - Блокировка пользователей

2. **Назначение тренеров**
   - Привязка клиентов к тренерам
   - Управление отношениями

3. **Статистика**
   - Общее количество пользователей
   - Активность
   - Метрики использования

4. **Настройки системы**
   - Конфигурация
   - Логи

**Полный доступ ко всем данным**

## Безопасность - Row Level Security (RLS)

### Policies для Client:
```sql
-- Клиент видит только свои данные
CREATE POLICY "client_view_own_data" ON profiles
  FOR SELECT USING (auth.uid() = user_id);

-- Клиент видит только свои тренировки
CREATE POLICY "client_view_own_workouts" ON workout_programs
  FOR SELECT USING (
    client_id = (SELECT id FROM profiles WHERE user_id = auth.uid())
  );
```

### Policies для Trainer:
```sql
-- Тренер видит своих клиентов
CREATE POLICY "trainer_view_clients" ON profiles
  FOR SELECT USING (
    id IN (
      SELECT client_id FROM trainer_client_relationships
      WHERE trainer_id = (SELECT id FROM profiles WHERE user_id = auth.uid())
    )
  );

-- Тренер может создавать программы для своих клиентов
CREATE POLICY "trainer_create_programs" ON workout_programs
  FOR INSERT WITH CHECK (
    trainer_id = (SELECT id FROM profiles WHERE user_id = auth.uid())
  );
```

### Policies для Admin:
```sql
-- Админ видит всё
CREATE POLICY "admin_view_all" ON profiles
  FOR ALL USING (
    (SELECT role FROM profiles WHERE user_id = auth.uid()) = 'admin'
  );
```
